# Como instalar o Brilhinhos no tablet

O Brilhinhos é um aplicativo que roda pelo navegador (igual ao PintaKids e ao TocaKids).
Depois de instalado, ele aparece com ícone na tela inicial, abre em tela cheia e funciona
**sem internet**.

1. O jogo precisa estar publicado num endereço da internet (ex.: GitHub Pages, como os outros
   apps). Depois de publicado, o endereço será algo como
   `https://diogogradizzi08-dot.github.io/brilhinhos/`.
2. No tablet, abra esse endereço no **Chrome**.
3. Toque nos **três pontinhos ⋮** (canto de cima) → **Adicionar à tela inicial** (ou
   **Instalar app**).
4. Abra pelo ícone novo. Pronto! Na primeira vez ele guarda tudo no tablet; depois funciona
   até sem Wi-Fi.

**O progresso fica salvo no próprio tablet** (no aplicativo). Limpar os dados do Chrome apaga
o jogo — cuidado.

Quando sair uma versão nova, basta abrir o app com internet: ele se atualiza sozinho.
